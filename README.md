# 🚀 LeadFlow CRM — Client Lead Management System

## Future Interns | Full Stack Web Development | Task 2

LeadFlow CRM is a Client Lead Management System (Mini CRM) developed as part of the Future Interns Full Stack Web Development Internship.

## ✨ Features

- Add new client leads
- View all leads
- Search leads
- Filter leads by status
- Update lead status
- Add and view notes
- Schedule follow-ups
- Delete leads
- MongoDB database storage
- REST API integration
- Responsive CRM dashboard
